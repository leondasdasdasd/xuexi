# 教材知识点管理优化测试报告

## 修改范围

- `src/routes/Exam/basicSetting.js`：重做基础设置页教材管理、知识点管理展示与教材挂知识点交互。
- `src/routes/Exam/basicSetting.less`：新增树形目录、知识点选择弹窗和响应式样式。
- `src/routes/Exam/basicSetting.helpers.js`：抽出教材册 mock、树操作、知识点路径、最深知识点选择等业务纯函数。
- `src/routes/Exam/basicSetting.helpers.test.js`：新增业务逻辑测试。
- `mockApi/mock/basicSetting.js`、`mockApi/index.js`：补充基础设置 mock 数据与接口映射，支持本地验收。

## 关键实现

- 教材管理筛选调整为“学段、学科、版本、册别”，学段展示为“幼儿园、小学、初中、高中”。
- 教材册使用前端 mock 数据，按版本和册别维护独立目录；人教版、青岛版上下册目录均不共用。
- 教材目录改为树形展示，只显示目录节点名称，不再显示“一级｜/二级｜”前缀，也不再单独显示“类型”列。
- 树节点最大支持 7 层，第 6 层可新增第 7 层，第 7 层不显示“新增下级”。
- 教材目录操作直接绑定在树节点行上；顶部“新增”和行内“新增”统一打开新增弹窗，可填写节点名称并自选上级节点。
- 行内“新增”默认以上级为当前节点，默认新增当前节点子节点；用户可改选“无上级”或其他上级节点，从而新增一级节点或平行节点。
- 节点行支持同级上移、下移。
- 每个教材节点行内直接展示已关联知识点，行内可打开关联弹窗，也可点击知识点 tag 上的“×”取消该节点对应知识点。
- 知识点管理只按学段和学科筛选，知识点名称只显示节点本身。
- 知识点管理操作与教材目录保持一致：顶部/行内“新增”统一打开弹窗，支持填写名称、选择上级；行内默认当前知识点为上级。
- 知识点节点支持同级上移、下移、保存、删除确认；不显示教材专属的“关联知识点”列。
- 教材节点可打开知识点关联弹窗，支持搜索、横向多级展开、主/次标记、取消选择；保存后目录行只显示末级知识点名称，完整路径放在 tooltip 中。

## 手工验证结果

- 打开 `http://127.0.0.1:8021/#/basicSetting`：基础设置页可进入，无白屏；服务编译成功，只有项目既有 Babel loose warning。
- 教材管理筛选：弹窗顺序为学段、学科、版本、册别；学段包含幼儿园、小学、初中、高中。
- 教材目录：每个节点行直接展示“目录名称、关联知识点、操作”；未出现“类型”列；节点输入值未出现“一级｜/二级｜/三级｜”前缀。
- 树操作：顶部“新增”默认无上级；行内“新增”默认当前节点为上级；弹窗内可调整上级节点，确认后按所选上级新增节点；“上移/下移”只调整同级顺序，不打散子节点。
- 新增弹窗：包含“节点名称”和“上级节点”；从第一单元行内进入时默认上级为“第一单元 语言基础”，改选“无上级（一级节点）”后可新增一级平行节点。
- 删除确认：教材目录行点击“删除”后先进入“删除节点”确认弹窗，确认后才删除当前节点及其子节点。
- 版本/册别切换：小学数学青岛版上册为“第一章 基本的几何图形”等目录；青岛版下册切换为“第五章 代数式与函数初步”等目录，确认不是共用同一棵树。
- 层级限制：在人教版数学上册中，第 6 层“符号变化检查”可以新增“新课时”作为第 7 层；第 7 层行只显示“关联知识点、保存、删除”，不显示“新增下级”。
- 知识点关联：点击任意教材节点行内“关联知识点”可打开弹窗；弹窗可搜索“数量比较”，可选择结果，可在“主/次”间切换；保存后该教材目录行显示末级知识点名称，不把完整路径作为可见文本铺在列表里。
- 取消关联：教材节点行内知识点 tag 带“×”；点击后该节点恢复“未关联”，其他教材节点不受影响。
- 知识点管理：切换到知识点管理后，筛选弹窗只显示学段和学科；知识点树输入值为“数的认识、20以内数的读写、数量比较”等纯名称。
- 知识点管理操作：表头为“知识点名称、操作”；每行显示“新增、上移、下移、保存、删除”，不显示“关联知识点”；点击行内“新增”弹出“新增知识点”，默认上级为当前知识点；点击“删除”弹出“删除节点”确认框。
- 响应式：使用浏览器 viewport 检查 1440、1140、768、390 宽度；页面文档级 `scrollWidth === clientWidth`，未出现整体横向溢出。390 宽度下关联弹窗宽度为 390，搜索框和“取消/确定”按钮均在视口内。

## 已知风险

- 当前教材版本、册别、教材目录仍是前端 mock；后续需要替换为后端教材版本/教材册接口。
- 教材节点保存接口目前沿用原 `chapter` 接口，`primaryKnowledgeIds` 只在前端状态中保留；后端若要保存主/次知识点，需要新增或扩展字段。
- 知识点树 mock 当前仍来自 `/api/knowledge/list`，实际后端需要保证只按学段、学科返回，不混入版本、年级、册别过滤。

## 后续接口对接点

- 教材版本列表接口：返回学段、学科下可选教材版本。
- 教材册列表接口：按学段、学科、版本返回册别，例如七年级上册、七年级下册。
- 教材目录接口：按教材册 id 返回独立目录树，并支持 7 层以内新增、编辑、删除。
- 教材知识点关联接口：保存 `knowledgeIds` 与 `primaryKnowledgeIds`，并返回末级名称和完整路径用于回显与 tooltip。
