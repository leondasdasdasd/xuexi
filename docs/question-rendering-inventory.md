# 题目渲染位置汇总

本文档汇总项目内与题目渲染相关的页面、入口文件和共享组件。页面地址统一使用本地推荐域：
`https://task.local.yungu-inc.org/exam#<route>`。动态路由参数保留为
`:examId`、`:paperId` 等占位符。

## 识别口径

- 包含只读展示、作答、批改、分析、错题订正、试卷预览、题目录入和题目编辑器。
- 题目富文本主要通过 `dangerouslySetInnerHTML`、`SlateRichEditor`、题目卡片组件或 PDF/图片预览 iframe 渲染。
- 已识别的核心题目数据形状包括：`content/questionContent`、`optionList/answersModelList`、`answer`、`analysis`、`gapFillingAnswer`、`sonQuestionList`、`type/questionType`、`studentAnswer/studentGapFillingAnswer`、`studentAnswerPicture/studentAnswerUrl`、`questionScore/questionSerialNumber`。
