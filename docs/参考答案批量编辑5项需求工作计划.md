# 参考答案批量编辑 5 项需求工作计划

## 1. 修复填空题答案同步

- 目标：单题编辑保存后的填空题答案，进入「参考答案」批量编辑后显示最新内容。
- 实现：批量编辑打开时基于最新 `questions` 重建答案草稿；外部题目更新且未处于批量编辑中时同步刷新草稿。
- 验证：单题编辑填空答案后，批量编辑能看到最新答案；普通填空题和组合题填空子题都覆盖。

## 2. 「添加可接受答案」改为「添答案」

- 目标：批量编辑填空题按钮更短，减少横向拥挤。
- 实现：按钮可见文案改为 `添答案`；保留完整 `aria-label` / `title` 语义。
- 验证：页面不再显示长文案；点击后同一空位新增一个可接受答案输入框。

## 3. 「添加填空 / 增加一个空」改为「添空」

- 目标：新增空位按钮统一为短文案。
- 实现：按钮可见文案改为 `添空`；保留完整 `aria-label` / `title`。
- 验证：点击后新增 `第2空`，已有答案不丢失。

## 4. 「删除当前空」改为垃圾桶图标

- 目标：删除当前空位只显示图标，不显示文字。
- 实现：使用现有 Ant Design `delete` 图标；保留 `aria-label="删除当前空"` 和 `title`；只剩一个空时仍禁用。
- 验证：批量编辑中无 `删除当前空` 可见文字；图标按钮可删除多余空位。

## 5. 组合题支持对子题批量设分

- 目标：组合题可统一设置所有子题分数，父题总分自动汇总。
- 实现：组合题区域增加「每小题」设分控件；批量设置所有 `subQuestionDrafts[].scoreText`；自动把父题 `scoreText` 设为子题分数之和；单独改子题分数时也同步重算父题总分。
- 验证：组合题 26 批量设每小题 4 分后，子题均为 4，父题总分为 16；保存后再次进入批量编辑仍一致。
